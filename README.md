Skyward Flight is a complete 3D bush-plane flight game that plays offline in a desktop browser from static files. Fly the Kestrel K-7 over Alder Valley: thread glowing sky rings, race the clock through the western canyon, or cross the lake and set her down gently on the Islet Strip. It has a real flight model (lift, stalls, banked turns, fuel), a lit instrument panel with attitude, airspeed, altimeter and heading, and synthesised engine and wind audio.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Arrow keys fly, W/S work the throttle, hold the mouse to steer, G lowers the gear, C switches to the cockpit view.
